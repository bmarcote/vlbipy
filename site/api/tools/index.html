Tools¶

Shared utility functions for vlbipy. Contains shell command execution, date conversions, disk space checks, and environment detection helpers.

tools ¶

Small shared utilities for vlbipy (time conversion, downloads, file helpers).

Recycled and modernized from the earlier casa_pipeline project: the wget/md5sum subprocess calls are replaced with urllib/hashlib so vlbipy has no shell-tool dependencies. All network access in vlbipy goes through :func:fetch_url_text and :func:download_file so tests can monkeypatch them.

mjd2datetime(mjd) ¶

Convert a Modified Julian Date (in days) to a naive UTC datetime.

mjdsec2datetime(mjd_seconds) ¶

Convert an MJD given in seconds (CASA convention) to a naive UTC datetime.

datetime2mjd(date) ¶

Convert a naive UTC datetime to a Modified Julian Date (in days).

natsort_key(text) ¶

Return a natural-sort key so that 'IDI2' sorts before 'IDI10'.

chunkert(counter, max_length, increment) ¶

Yield (start, n) chunks covering [counter, max_length) in steps of increment.

space_available_gb(path) ¶

Return the available disk space (in GB) on the filesystem containing path.

collect_casa_logs(log_dir, search_dirs=None) ¶

Move stray casa*.log files into log_dir; return what was moved.

CASA writes a log named for the moment it starts into whatever directory the process happens to be in, so a working directory accumulates one file per invocation. Everything a run produces belongs under the project directory, so these are swept up rather than left scattered around the shell's cwd.

Existing names are never overwritten: a colliding file gets a numeric suffix, because two CASA sessions started in the same second would otherwise lose one of the two logs.

Parameters¶

log_dir : str or pathlib.Path Destination directory (created if needed). search_dirs : iterable, optional Directories to sweep; defaults to the current working directory.

Returns¶

list of pathlib.Path The new locations of the moved files.

md5sum(path) ¶

Return the hex MD5 checksum of a file (streamed, so large files are fine).

fetch_url_text(url, username=None, password=None, timeout=120.0) ¶

Fetch a URL and return its body decoded as text.

Raises¶

ConnectionError On HTTP/network failure, with a hint about credentials on 401/403.

download_file(url, dest, username=None, password=None, timeout=600.0) ¶

Download a URL to dest (a file path), streaming to disk; return the path.

Raises¶

ConnectionError On HTTP/network failure, with a hint about credentials on 401/403.

fetch_eop_file(directory) ¶

Fetch the USNO EOP file (usno_finals.erp) needed by gencal caltype='eop'.

An already-present file in directory is reused. Otherwise the HTTPS mirrors are tried first, then the CDDIS FTPS archive via curl --ftp-ssl.

Raises¶

ConnectionError If no source could provide the file (set [calibration].eop_file).

gunzip(path, remove_original=True) ¶

Decompress a .gz file next to itself; return the decompressed path.
